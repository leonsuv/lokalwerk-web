# Security

Please report security issues by email to **kontakt@lokalwerk.eu**, not as a public issue. Include the affected page or file and the steps to reproduce.

---

Sicherheitsprobleme bitte per E-Mail an **kontakt@lokalwerk.eu** melden, nicht als öffentliches Issue. Bitte die betroffene Seite oder Datei und die Schritte zum Nachvollziehen angeben.
