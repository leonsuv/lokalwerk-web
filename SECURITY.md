# Security

Please report security issues by email to **support@azendix.de**, not as a public issue. Include the affected page or file and the steps to reproduce.

---

Sicherheitsprobleme bitte per E-Mail an **support@azendix.de** melden, nicht als öffentliches Issue. Bitte die betroffene Seite oder Datei und die Schritte zum Nachvollziehen angeben.
