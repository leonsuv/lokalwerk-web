QR-Code für Überweisungen (EPC-QR-Code)

Einen QR-Code erstellen, den Banking-Apps als Überweisung einlesen, zum Beispiel für Spendenaufrufe, Mitgliedsbeiträge oder Aushänge.

Leer lassen, wenn der Zahlende den Betrag selbst eintragen soll, etwa bei Spenden.

QR-Code

Gib Empfänger und IBAN ein, dann erscheint hier der Code.

Angaben als Text unter den Code

Gilt für das PNG; das SVG enthält nur den Code. So kann der Zahlende vergleichen, ob der Code dasselbe enthält.

Teste den Code vor dem Druck mit deiner eigenen Banking-App: Scanne ihn, prüfe Empfänger, IBAN, Betrag und Verwendungszweck und brich die Überweisung dann ab.

So funktioniert es

Trag Empfänger und IBAN ein, bei Bedarf Betrag und Verwendungszweck. Der Code entsteht sofort. Wer ihn mit der Banking-App scannt, bekommt eine fertig ausgefüllte Überweisung und muss sie dort nur noch prüfen und freigeben. Der Code folgt den Leitlinien EPC069-12 des European Payments Council, Version 3.1.

Gut zu wissen

Nicht jede Banking-App liest diese Codes. Zeichen, die im SEPA-Zahlungsverkehr nicht erlaubt sind, werden umgeschrieben, zum Beispiel é zu e; das steht dann unter dem Feld. Der Name darf höchstens 70 Zeichen haben, der Verwendungszweck 140. Unterstützt werden Konten in Ländern der EU und des EWR. Die BIC brauchst du dort nicht.

Nichts wird gesendet oder gespeichert

Der Code entsteht direkt in deinem Browser. Deine Angaben werden weder gesendet noch gespeichert. Nach dem Laden der Seite funktioniert das Werkzeug auch ohne Internetverbindung.
